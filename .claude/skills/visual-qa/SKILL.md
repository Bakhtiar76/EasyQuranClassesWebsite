# Visual QA

- Target the local site during development.
- Check representative desktop, laptop, tablet and mobile widths.
- Verify overflow, typography, image crops, navigation, cards, forms, buttons, focus states and touch targets.
- Check console/network errors.
- Compare to client reference screenshots and `DESIGN.md`.
- Capture only useful screenshots; do not commit auth/session state.
- Repeat a production smoke visual check after cPanel deployment.
