# cPanel Audit

The account has no Shell/SSH/Terminal.

Do not attempt remote shell or install cPanel MCP.

Ask the user to provide/confirm only needed cPanel values/screenshots:
- production domain/document root;
- existing site state;
- PHP version;
- File Manager upload limits;
- DB/phpMyAdmin availability/import limits;
- backup/JetBackup availability;
- SSL status;
- cache/CDN;
- disk space;
- email/form delivery dependencies.

Do not change anything during audit. Never request passwords in chat.
