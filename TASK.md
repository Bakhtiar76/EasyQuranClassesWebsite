# TASK — Configure Claude Code + Local WordPress Development for Easy Quran Classes

## Purpose

Configure this repository and local machine so Claude Code can build, design, test and package the Easy Quran Classes WordPress/Elementor website **locally** and later hand off a safe release for manual cPanel deployment.

### Confirmed hosting constraint

The client's cPanel account has **no Shell/SSH/Terminal access**.

Therefore:
- do not attempt remote SSH;
- do not plan remote WP-CLI;
- do not configure rsync/SCP deployment;
- do not install cPanel/SSH/database MCP servers;
- do not build the website directly in production;
- cPanel interaction is deployment-stage, user-controlled web UI work.

This task is for environment/tooling setup only. Do not start the website pages until setup is verified.

Use the existing healthy stack if one already exists.

# 8. Phase E — permissions and hooks

Inspect the installed Claude Code version/current schema before writing `.claude/settings.json`.

Keep machine-specific permissions in ignored local settings where appropriate.

## Permission goals
Deny/read-protect obvious secrets and backup/release artifacts where supported.

Require confirmation for high-impact local actions such as:
- `git push`;
- force push/history rewrite;
- broad file deletion;
- local DB reset/drop/import;
- broad WordPress search-replace that mutates the working DB;
- system-wide package installs;
- commands targeting the production domain;
- release packaging/deployment actions that could contain secrets.

Do **not** create SSH/cPanel allow rules because remote shell is unavailable.

## Hooks
Create only useful local hooks:

### Destructive command guard
Protect against broad delete, destructive Git commands, local DB drop/reset and accidental commands targeting production.

### Lightweight post-edit validation
Use cheap targeted checks only, e.g. PHP syntax or JSON parse when applicable.

### Optional completion guard
Only if reliable and low-noise; check incomplete TODOs, unverified changes and temporary/debug artifacts.

Test each hook with harmless synthetic examples.
